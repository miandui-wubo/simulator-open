# 接触角计算工具 - 协方差矩阵/PCA方法

## 简介

本工具使用协方差矩阵/PCA方法从COMSOL仿真的液滴点云数据计算接触角。该方法基于Santiso等人的研究，通过拟合局部切平面来计算液-气界面的法向量，进而求得接触角。

## 算法原理

1. **数据加载**: 读取COMSOL导出的txt点云数据（x, y, z坐标）
2. **接触线识别**: 筛选z≈0的点作为接触线区域
3. **局部法向计算**: 对每个接触点使用k近邻构建协方差矩阵，通过特征值分解获得局部切平面法向
4. **接触角计算**: 平均所有局部法向，与固体表面法向(0,0,1)点积求接触角

### 基本用法

```bash
python contact_angle_pca.py
```

### 自定义参数

编辑 `contact_angle_pca.py` 中的参数：

```python
calculator = ContactAngleCalculator(
    z_threshold=0.05,    # 接触线区域阈值（调整此值以包含更多/更少接触点）
    k_neighbors=30,      # k近邻数量（增大以平滑噪声，减小以提高局部精度）
    min_points=10        # 最少接触点数（数据质量检查）
)
```

### 修改输入文件

修改 `main()` 函数中的路径：

```python
input_file = "/path/to/your/data.txt"
output_dir = "/path/to/output/directory"
```

## 输入文件格式

COMSOL导出的txt文件，包含表头和数据行：

```
x                       y                        z                        IsoLevel
-1.1936161370256426     -1.884679071746396       0.3589070385199583       0.5
-1.1512869369305017     -1.9086545917978297      0.35873599156283215      0.5
...
```

- 第一行为表头
- 后续行为点云数据，至少包含x, y, z三列
- IsoLevel列可选（程序只使用前三列）

## 参数调整指南

### z_threshold (接触线区域阈值)

- **默认值**: 0.05
- **作用**: 定义哪些点属于接触线区域（z < z_threshold）
- **调整建议**:
  - 如果接触点太少：增大阈值（如0.1）
  - 如果包含过多上方的点：减小阈值（如0.02）
  - 查看控制台输出的"接触线点数"进行判断

### k_neighbors (k近邻数量)

- **默认值**: 30
- **作用**: 用于构建协方差矩阵的邻居点数
- **调整建议**:
  - 数据噪声大：增大k值（如50）以平滑
  - 需要更高局部精度：减小k值（如20）
  - 点云密度低：减小k值避免过度平滑

### min_points (最少接触点数)

- **默认值**: 10
- **作用**: 数据质量检查，接触点少于此值时报错
- **调整建议**: 根据数据集大小调整

## 原理参考

该方法适用于：
- 分子模拟/微观多孔介质的点云数据
- 只有界面点云，没有完整Level Set场的情况
- 需要计算三维接触角分布的场景

优势：
- 不需要曲线/曲面拟合
- 对>180°接触角也适用
- 可扩展到三维分布分析

## 故障排除

### 问题: "接触线点数太少"

**解决**: 增大 `z_threshold` 参数

### 问题: 接触角异常（过大或过小）

**检查**:
1. 查看可视化图像，确认接触线区域是否合理
2. 调整 `z_threshold` 和 `k_neighbors`
3. 确认固体表面是否为z=0平面

### 问题: 计算时间过长

**解决**: 减小 `k_neighbors` 或使用更少的接触点
